# SEO перед запуском APPGRADE

В проекте добавлены отдельные заголовки, описания, Open Graph и canonical для главной, каталога, 13 категорий, Trade-In и страниц магазинов. Карточки вариантов имеют один канонический адрес модели; старые адреса перенаправляются с сохранением выбранного артикула. В каждой категории есть обычные HTML-ссылки на все модели, включая товары за кнопкой «Показать ещё».

JSON-LD описывает организацию, сайт, конкретный товар, характеристики и хлебные крошки. Для магазинов с заполненными адресом и телефоном добавлена ElectronicsStore. Рейтинги, отзывы, сроки доставки и неизвестные адреса в разметку не добавляются. Product не содержит Offer: цены и остатки зависят от города и обновляются в базе. Без синхронизации разметки с актуальным прайсом и видимой ценой обещать расширенный результат с ценой нельзя.

Товар с неуточнённой моделью и ограниченными характеристиками исключается из sitemap и получает noindex до исправления данных. Остальные товары не исключаются только из-за отсутствия проверенного фото.

## Действия после подготовки сервера

1. Задайте APP_ORIGIN и NEXT_PUBLIC_SITE_URL равными https://аппгрейд.рф и пересоберите сайт. При localhost индексация закрыта, JSON-LD не публикуется, sitemap пустой.
2. Направьте домен на VPS, настройте HTTPS и единый основной адрес без www. Перенаправляйте HTTP и www на основной HTTPS-домен на прокси.
3. Проверьте /robots.txt, /sitemap.xml, canonical, отсутствие noindex на публичных страницах и ответы 404 для неизвестных товаров.
4. Добавьте домен в Яндекс Вебмастер и Google Search Console. Коды подтверждения можно задать через YANDEX_SITE_VERIFICATION и GOOGLE_SITE_VERIFICATION, затем пересобрать сайт. Отправьте карту сайта.
5. Проверьте JSON-LD и отображение страниц после публикации. Индексация и расширенное отображение зависят от поисковой системы.
6. Заполните настоящие адрес, телефон и часы работы в Сибае. Подтвердите остальные контакты и карточки магазинов в Яндекс Картах/2ГИС.
7. После запуска измерьте скорость на мобильных устройствах и реальные Core Web Vitals. Проверьте сервер под нагрузкой, затем оптимизируйте по результатам измерений.

Админка, API, корзина, избранное и юридические служебные страницы не предназначены для поисковой выдачи. В sitemap включены только публичные основные адреса без параметров выбора товара и поиска. Даты изменения не подставляются выдуманным ежедневным значением.

## Проверено 4 октября 2026 года

- Production-сборка с NEXT_PUBLIC_SITE_URL=https://аппгрейд.рф прошла проверку TypeScript.
- Через HTTP проверены все 1320 адресов из sitemap: статус 200, один правильный canonical, title, description, один H1, JSON-LD и отсутствие noindex.
- Отдельно проверены закрытые служебные страницы, заголовок noindex у API, 404 для неизвестных страниц и некорректных SKU, постоянный редирект старого адреса и соответствие разметки выбранному артикулу.
- Товар с неуточнённой моделью исключён из sitemap и имеет noindex.
- Все 70 тестов прошли; lint изменённых SEO-файлов прошёл.

Проверка выполнена локально, сайт ещё не опубликован на домене. Регистрация в поисковых кабинетах и реальные показатели скорости VPS проверяются после публикации. Визуальный браузерный предпросмотр в текущем режиме недоступен.
