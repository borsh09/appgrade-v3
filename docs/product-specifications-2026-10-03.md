# Характеристики товаров

На всех 1572 страницах товаров подключён единый блок характеристик. Выбранный артикул, модель, цвет, память, SIM, подключение, размер и комплектация берутся из актуального каталога. Технические сведения разбиты на группы: экран, производительность, камеры, питание, связь и корпус.

Обновлено 4 октября 2026 года. Технические данные доступны для 1571 из 1572 артикулов. Единственное исключение — `P-34586308`, «OnePlus Nord N6 4/128 Green»: название не подтверждено производителем, требуется уточнить модель у поставщика. Для него отображаются параметры выбранной конфигурации и пометка об уточнении дополнительных характеристик. Перечень исключений — в `product-specifications-coverage.json`. Отражены проверенные доступные сведения, а не обещание заполнения каждого возможного поля спецификации.

Данные: `parser-details.json`, `parser-curated-details.ts`, `current-product-details.json`, `verified-model-specifications.ts`, `official-model-specifications.json`, `structured-manufacturer-specifications.json`. В записях сохранены ссылки на источник. Дополнены официальные характеристики смартфонов, компьютеров, планшетов, часов, аудиотехники, камер, игровых устройств и аксессуаров. Для игр добавлены платформа, жанр и режимы. Проверенные вручную профили имеют приоритет над автоматически извлечёнными таблицами.

Параметры разных поколений, Pro/Max/Plus/FE и соседних линеек не объединяются. Общие технические сведения модели не переносят память, цвет, SIM или комплект другого артикула. Для MacBook из общей записи исключены конфигурации CPU/GPU, для часов — размеры и материалы конкретного корпуса и ремешка. Спорные источники из `parser-details-review.json` исключены.

Обновление данных: `scripts/fetch-current-product-details.ts`, `scripts/fetch-official-product-specifications.ts`, `scripts/import-huawei-specifications.ts`, `scripts/fetch-xiaomi-specifications.ts`. Повторный отчёт: `scripts/audit-product-specifications.ts`.

Проверки: 67 тестов прошли, TypeScript и проверка изменённых файлов линтером прошли. Производственная сборка собрана. Все 1572 карточки прошли HTTP-проверку: статус 200, один раздел характеристик, правильные модель, артикул и цвет; пометка об уточнении присутствует только у неподтверждённого OnePlus. Результаты: `.tmp-qa/specifications-http-results.json`. Локальный сайт доступен на `http://127.0.0.1:3000`.

Общая проверка линтером обнаруживает отдельные существующие замечания в скриптах импорта фотографий; эти файлы не менялись при добавлении характеристик.
