# AppGrade на Beget VPS

Сервер: `appgrade-production`, Ubuntu 24.04, `159.194.254.202`.
Проект на сервере: `/opt/appgrade`.
Домен: `аппгрейд.рф` (`xn--80agddu7aaj.xn--p1ai`).

## Управление

```sh
cd /opt/appgrade
docker compose -f compose.yaml -f compose.production.yaml -f compose.media.yaml ps
docker compose -f compose.yaml -f compose.production.yaml -f compose.media.yaml logs --tail=100 web
docker compose -f compose.yaml -f compose.production.yaml -f compose.media.yaml up -d --build
```

`compose.media.yaml` подключает `./public` к `/app/public` контейнера. Сохраняйте этот файл при обновлениях: изображения передаются отдельно от кода. Секреты находятся в приватном `/opt/appgrade/.env`; не добавляйте его в Git или публичные архивы.

Приложение доступно локально на `127.0.0.1:3000`; PostgreSQL не имеет публичного порта. Caddy обслуживает порты 80/443. Сайт работает по `https://аппгрейд.рф`. Адрес `www.аппгрейд.рф` и HTTP по IP перенаправляются на основной HTTPS-домен с сохранением пути.

## Резервные копии

Первая копия PostgreSQL создана в `/opt/appgrade/var/backups`. Ежедневный запуск настроен через `/etc/cron.daily/appgrade-backup`. Ручной запуск:

```sh
cd /opt/appgrade
sh scripts/backup-db.sh
```

Дополнительно требуется внешнее хранение копий и проверка восстановления. Не выполняйте `docker compose down -v`: это удалит volumes с базой и загрузками.
